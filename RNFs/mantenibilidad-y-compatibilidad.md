# Requisitos No Funcionales - Mantenibilidad y Compatibilidad

## RNF003 - Compatibilidad
- ID: RNF003
- Descripción: El sistema debe funcionar correctamente en los navegadores Chrome, Firefox y Edge sin necesidad de plugins adicionales.
- Priorización: Alta
- Detalle técnico: Debe validarse el comportamiento en navegadores modernos y resoluciones compatibles con el diseño responsive.
- Criterio de cumplimiento: La plataforma es accesible y funcional en los navegadores soportados.

## RNF006 - Mantenibilidad
- ID: RNF006
- Descripción: El código fuente debe seguir buenas prácticas de documentación y desarrollo para facilitar mantenimiento y evolución.
- Priorización: Media
- Detalle técnico: Se deben aplicar estándares de calidad, modularización y procesos de integración continua.
- Criterio de cumplimiento: El sistema puede actualizarse o corregirse sin afectar de manera crítica su funcionamiento.
