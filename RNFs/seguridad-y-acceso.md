# Requisitos No Funcionales - Seguridad y Acceso

## RNF001 - Seguridad
- ID: RNF001
- Descripción: El sistema debe proteger los datos del usuario mediante HTTPS y control de acceso basado en roles.
- Priorización: Alta
- Detalle técnico: Se deben implementar autenticación segura, autorización por rol y cifrado en tránsito para toda comunicación cliente-servidor.
- Criterio de cumplimiento: El sistema protege la sesión del usuario y evita accesos no autorizados.

## RNF007 - Usabilidad
- ID: RNF007
- Descripción: La interfaz debe ser intuitiva, accesible y usable por usuarios técnicos sin experiencia previa con la plataforma.
- Priorización: Alta
- Detalle técnico: La experiencia de usuario debe permitir completar un análisis completo en menos de 5 minutos desde el primer acceso.
- Criterio de cumplimiento: Un usuario nuevo puede completar el flujo principal sin capacitación formal.
