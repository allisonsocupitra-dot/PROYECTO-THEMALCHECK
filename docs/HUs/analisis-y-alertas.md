# Historias de Usuario - Análisis y Alertas

## HU-08: Análisis automático de imágenes
- Como usuario, quiero que el sistema analice automáticamente las imágenes térmicas cargadas, para obtener resultados sin intervención manual.

### Criterios de aceptación
1. El análisis se ejecuta automáticamente tras cargar una imagen válida.
2. El sistema muestra los resultados del análisis en la interfaz.
3. El usuario no necesita configurar parámetros adicionales para iniciar el proceso.

## HU-09: Detección de anomalías térmicas
- Como usuario, quiero que el sistema identifique zonas con temperaturas fuera del rango normal, para detectar posibles fallas eléctricas.

### Criterios de aceptación
1. El sistema resalta visualmente las zonas anómalas en la imagen analizada.
2. La detección se realiza sobre la imagen cargada sin intervención manual.
3. Los resultados se presentan de forma clara para su revisión.

## HU-10: Generación de alertas
- Como usuario, quiero recibir alertas visuales cuando se detecten patrones térmicos peligrosos, para tomar acciones preventivas oportunas.

### Criterios de aceptación
1. El sistema muestra una alerta cuando detecta una anomalía crítica.
2. La alerta se presenta antes de cerrar el análisis.
3. La notificación es visible y comprensible para el usuario.
