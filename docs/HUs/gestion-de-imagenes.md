# Historias de Usuario - Gestión de Imágenes

## HU-04: Carga de imágenes térmicas
- Como técnico o usuario del sistema, quiero subir imágenes térmicas en formatos compatibles, para analizarlas automáticamente.

### Criterios de aceptación
1. El sistema admite imágenes en formato JPEG, PNG o TIFF.
2. La imagen se carga correctamente y se muestra en la interfaz.
3. Si el archivo no es compatible, el sistema informa el error de forma clara.

## HU-05: Visualización de imágenes
- Como usuario, quiero ver la imagen térmica cargada en pantalla, para inspeccionar visualmente el contenido antes del análisis.

### Criterios de aceptación
1. La imagen se renderiza en pantalla sin demora visible.
2. La visualización conserva la calidad y proporción original de la imagen.
3. El usuario puede observar la imagen completa en la interfaz principal.

## HU-06: Cambio de paleta de color
- Como usuario, quiero cambiar la paleta de visualización de la imagen, para interpretar mejor las variaciones térmicas.

### Criterios de aceptación
1. El usuario puede seleccionar entre diferentes paletas de color.
2. La imagen se actualiza en tiempo real al cambiar la paleta.
3. La paleta seleccionada se aplica correctamente al contenido visualizado.

## HU-07: Comparación de imágenes
- Como analista, quiero comparar dos imágenes térmicas del mismo equipo, para detectar diferencias de temperatura entre periodos o estados.

### Criterios de aceptación
1. El sistema permite cargar dos imágenes para visualización simultánea.
2. Ambas imágenes se muestran lado a lado sin deformación.
3. La comparación se puede realizar sin afectar el rendimiento general del sistema.
