# Historias de Usuario - Reportes

## HU-11: Generación de reportes
- Como usuario, quiero generar un reporte con los resultados del análisis térmico, para conservar un registro de la evaluación realizada.

### Criterios de aceptación
1. El sistema genera un reporte con los resultados del análisis.
2. El reporte se descarga en formato PDF.
3. El contenido del reporte incluye la información relevante del análisis.

## HU-12: Consulta de historial de análisis
- Como usuario, quiero consultar los análisis realizados anteriormente, para revisar resultados previos y comparar tendencias.

### Criterios de aceptación
1. El sistema almacena un historial de análisis por usuario.
2. El usuario puede ver la fecha, el estado y el resultado de cada análisis.
3. El historial permite identificar evaluaciones anteriores de forma rápida.

## HU-13: Exportación de resultados
- Como usuario, quiero exportar los resultados del análisis en formatos compatibles, para compartirlos o archivarlos.

### Criterios de aceptación
1. El sistema permite exportar resultados en PDF o Excel.
2. El archivo exportado contiene todos los datos del análisis.
3. La descarga se completa correctamente sin errores.
